# Mauri-Dev v2 — Plan 2: Security headers, CLS fix, and the admin panel

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Deliver the full security header set on real HTTP responses, close the Arabic CLS regression, and ship a password-protected `/admin` that manages projects and site settings from the browser — with the public site reading from the store and never rendering empty.

**Architecture:** Two prerequisites land before any admin route exists: headers move from `netlify.toml` (which the Next runtime bypasses for documents) into `next.config.mjs` `headers()`, and the Arabic font fallback gets tuned metrics. Then the admin is built bottom-up: a typed `ContentStore` over Netlify Blobs with the bundled data as fallback, argon2 + `jose` auth with Blobs-backed rate limiting, server actions validated with zod, and a `sharp` re-encode pipeline for uploads. The public page switches to reading the store last, once there is something to read.

**Tech Stack:** Next.js 16 (App Router, Turbopack), React 19, TypeScript 5 strict + `noUncheckedIndexedAccess`, Tailwind 3, `@netlify/blobs`, `jose`, `@node-rs/argon2`, `zod`, `sharp`, Playwright.

**Source spec:** `docs/superpowers/specs/2026-07-27-mauri-dev-v2-design.md` §3.5–3.7, plus the outstanding B12 half from plan 1.

## Global Constraints

Every task's requirements implicitly include this section.

- **The repository is PUBLIC.** No secret value reaches git — not in a committed file, not in `.env.example`, not in a comment, not in a test fixture. `.env.example` lists variable **names** with empty values only. `ADMIN_PASSWORD_HASH` and `AUTH_SECRET` live **only** in Netlify environment variables.
- **No secret is ever prefixed `NEXT_PUBLIC_`.** Anything with that prefix is compiled into the client bundle and served to every visitor. Task 12 greps for it as a gate.
- **Every task ends green:** `npx tsc --noEmit`, `npm run lint`, `npm run build` — no errors, **no warnings**, no `@ts-ignore`, no `any`.
- **`main` is never broken.** All work lands on `feat/v2`.
- **The public site must never render empty.** A missing, cold or unreachable blob falls back to the bundled `src/data/projects.ts` / `src/lib/site.ts`. Those files remain the typed default and are never deleted.
- **Three dictionaries stay structurally identical.** `en.ts` is the type source of truth. The admin UI is English/LTR and does **not** use the public dictionaries.
- **`category` (`web`|`app`) and `frame` (`phone`|`browser`) stay distinct.** `category` drives the filter and lightbox layout; `frame` drives only the card cover. Label them unambiguously in the admin UI.
- **`src/data/blur.generated.ts` is generated.** Never hand-edit. `gen-blur.mjs` keeps owning the bundled images; uploads generate their own LQIP at upload time.
- **Never delete or rewrite an entry in `src/data/projects.ts` without asking the owner.**
- **PROTECTED TESTS — no task may weaken or remove these.** Each exists because a real regression passed a weaker check:
  - _Computed `font-family` per locale_ (`tests/smoke.spec.ts`, task 9 of plan 1).
  - _Computed `opacity > 0` on at least one reveal per section_ (task 10b of plan 1).
  - _Hero headline and project cards visible with JavaScript disabled_ (task 11 of plan 1).
  - _Headers asserted on a deployed response, not on config_ (task 1 of this plan).
- **Import `m` from `motion/react-m`, never from `motion/react`.** The barrel also exports the full `motion` proxy; importing `m` through it measured +2.4 KB versus doing nothing.
- **Never render markup that branches on the current theme.** The server cannot know it. Use the `dark:` variant. This shipped as React error #418 once already.
- **The admin bundle must not add a single byte to the public page's first load.** Task 12 measures `/ar` before and after and the number must not move.
- **Measurement scripts own their server.** `node scripts/measure-bundle.mjs` and `scripts/measure-cls.mjs` kill whatever holds their port and refuse to report against a server they did not start.

```ts
      const h = response.headers();

      expect(h['referrer-policy']).toBe('strict-origin-when-cross-origin');

      expect(h['permissions-policy']).toContain('microphone=()');

      expect(csp).toContain("frame-ancestors 'none'");
      expect(csp).toContain("default-src 'self'");
      expect(csp).toContain("object-src 'none'");
      expect(csp).toContain("base-uri 'self'");
    });
  }

  test('/admin is not indexable', async ({ request }) => {
    const response = await request.get('/admin');
    expect(response.headers()['x-robots-tag']).toContain('noindex');
```

- [ ] **Step 3: Move the headers into next.config.mjs**

`headers()` is served by the framework, so it applies to the function's document responses — which is the half that was missing.

```js
/**
 * Security headers.
 *
 * These live here, not in netlify.toml, because netlify.toml headers are
 * applied by the CDN to files it serves and pages come from the Next runtime's
 * function. Verified on a deploy: with the rules only in netlify.toml, static
 * assets carried the full set and every HTML document carried none of it.
 *
 * netlify.toml keeps the immutable cache rules, which it does apply correctly.
 */
const SECURITY_HEADERS = [
  { key: 'X-Content-Type-Options', value: 'nosniff' },
  { key: 'Referrer-Policy', value: 'strict-origin-when-cross-origin' },
  {
    key: 'Strict-Transport-Security',
    value: 'max-age=63072000; includeSubDomains; preload',
  },
  {
    key: 'Permissions-Policy',
    value: 'camera=(), microphone=(), geolocation=(), interest-cohort=()',
  },
];

/**
 * script-src carries 'unsafe-inline' on public routes and this is measured, not
 * lazy. A statically prerendered route emits 22 inline scripts, 21 of them
 * Next's own RSC flight payload, and a browser ignores 'unsafe-inline' the
 * moment any hash or nonce is present — so hashing only the no-flash script
 * would block the other 21 and the page would never hydrate. A nonce requires
 * per-request rendering, which forfeits the prerendering the whole architecture
 * is built on.
 *
 * /admin is different: it is dynamic by nature, so it gets a nonce and no
 * 'unsafe-inline' at all. That is where a session cookie lives, and it is the
 * surface worth spending the strictness on.
 */
const PUBLIC_CSP = [
  "default-src 'self'",
  "script-src 'self' 'unsafe-inline'",
  "style-src 'self' 'unsafe-inline'",
  "img-src 'self' data: blob:",
  "font-src 'self' data:",
  "connect-src 'self'",
  "frame-ancestors 'none'",
  "base-uri 'self'",
  "form-action 'self'",
  "object-src 'none'",
].join('; ');

const nextConfig = {
  reactStrictMode: true,
  images: {
    qualities: [55, 70, 75, 78],
    formats: ['image/avif', 'image/webp'],
  },
  async headers() {
    return [
      {
        source: '/:path*',
        headers: [
          ...SECURITY_HEADERS,
          { key: 'Content-Security-Policy', value: PUBLIC_CSP },
        ],
      },
      {
        source: '/admin/:path*',
        headers: [{ key: 'X-Robots-Tag', value: 'noindex, nofollow' }],
      },
    ];
  },
};

export default nextConfig;
```

Append to `tests/smoke.spec.ts`:

```ts
/**
 * PROTECTED TEST — do not weaken, skip, or delete.
 *
 * Arabic shipped a 0.059 CLS to production preview because the Tajawal faces
 * swap in after first paint and the fallback's metrics do not match. Local
 * measurement showed 0.0000 and could not have caught it: a localhost font
 * arrives before anything has painted.
 *
 * This test throttles the font response so the swap happens late enough to
 * measure, which is what makes a local run representative of a real network.
 */
test.describe('font swap layout stability', () => {
  for (const locale of ['ar', 'en'] as const) {
    test(`${locale} does not shift when its webfont swaps in`, async ({ page }) => {
      await page.route('**/_next/static/media/*.woff2', async (route) => {
        await new Promise((resolve) => setTimeout(resolve, 1200));
        await route.continue();
      });

      await page.addInitScript(() => {
        window.__cls = 0;
        new PerformanceObserver((list) => {
          for (const entry of list.getEntries()) {
            const shift = entry as PerformanceEntry & {
              value: number;
              hadRecentInput: boolean;
            };
            if (!shift.hadRecentInput) window.__cls += shift.value;
          }
        }).observe({ type: 'layout-shift', buffered: true });
      });

      await page.goto(`/${locale}`);
      await page.evaluate(() => document.fonts.ready);
      await page.waitForTimeout(1500);

      const cls = await page.evaluate(() => window.__cls ?? 0);
      expect(cls, `${locale} shifted by ${cls} when its font loaded`).toBeLessThan(0.05);
    });
  }
});
```

- [ ] **Step 4: Add a metric-matched fallback**

```ts
import localFont from 'next/font/local';

/**
 * Metric-matched fallback for Tajawal.
 *
 * `size-adjust` and the vertical overrides make the system Arabic fallback
 * occupy the same box as Tajawal, so the swap is invisible instead of costing
 * a 0.06 layout shift. The numbers come from measuring both faces in a browser
 * (see the plan's step 1) — they are not copied from a blog post, and they must
 * be re-measured if the font or its weights change.

const tajawalFallback = localFont({
  src: '../../../../public/fonts/tajawal-subset.woff2',
  variable: '--font-arabic-fallback',
  display: 'swap',
  adjustFontFallback: false,
  fallback: ['Segoe UI', 'Tahoma', 'sans-serif'],
  declarations: [
    { prop: 'size-adjust', value: '<measured>%' },
    { prop: 'ascent-override', value: '<measured>%' },
    { prop: 'descent-override', value: '<measured>%' },
    { prop: 'line-gap-override', value: '0%' },
  ],
});
```

```ts
import { z } from 'zod';
import type { Project } from '@/data/projects';

const LOCALES = ['ar', 'en', 'fr'] as const;

/** Every locale is required. A half-translated project is a build failure in
 *  the bundled data, so it must be a validation failure in the store too. */
const localizedString = z.object({
  ar: z.string().min(1),
  en: z.string().min(1),
  fr: z.string().min(1),
});

export const projectSchema = z.object({
  id: z
    .string()
    .min(1)
    .regex(/^[a-z0-9-]+$/, 'lowercase letters, digits and hyphens only'),
  title: localizedString,
```

```ts
import { verify } from '@node-rs/argon2';

/**
 * Verify a candidate password against the argon2id hash in the environment.
 *
 * Fails closed: a missing or malformed hash returns false rather than throwing
 * or, worse, treating the absence as a match. argon2's verify is constant-time
 * with respect to the hash, so there is no comparison to hand-roll.
 *
 * The plaintext password exists nowhere — not in the repo, not in the build,
 * not in an env var. Only the hash is deployed.
 */
export async function verifyPassword(candidate: string): Promise<boolean> {
  const hash = process.env.ADMIN_PASSWORD_HASH;
  if (!hash || candidate.length === 0) return false;
  try {
    return await verify(hash, candidate);
  } catch {
    return false;
  }
}
```

```ts
import { SignJWT, jwtVerify } from 'jose';

export const SESSION_COOKIE = 'md-session';
const EXPIRY = '8h';

function secret(): Uint8Array {
  const value = process.env.AUTH_SECRET;
  if (!value) throw new Error('AUTH_SECRET is not set');
  return new TextEncoder().encode(value);
}

export async function createSession(): Promise<string> {
  return new SignJWT({ role: 'admin' })
    .setProtectedHeader({ alg: 'HS256' })
    .setIssuedAt()
    .setExpirationTime(EXPIRY)
    .sign(secret());
}

/** Fails closed on every path: no token, bad signature, expired, or no secret. */
export async function verifySession(token: string | undefined): Promise<boolean> {
  if (!token) return false;
  try {
    const { payload } = await jwtVerify(token, secret());
    return payload.role === 'admin';
  } catch {
    return false;
  }
}
```

- [ ] **Step 7: Implement rate limiting**

Create `src/lib/auth/rate-limit.ts`:

```ts
import { getStore } from '@netlify/blobs';

const STORE = 'auth-attempts';
const MAX_ATTEMPTS = 5;
const WINDOW_SECONDS = 600;
const LOCKOUT_SECONDS = 900;

interface AttemptRecord {
  count: number;
  first: number;
  lockedUntil?: number;
}

function key(ip: string): string {
  // Namespaced so a crafted IP header cannot collide with another blob key.
  return `login:${ip.replace(/[^a-zA-Z0-9.:_-]/g, '_')}`;
}

/**
 * Five failures per ten minutes per IP, then a fifteen-minute lockout.
 *
 * Fails OPEN on a store error: an outage in Netlify Blobs must not lock the
 * owner out of their own admin panel. The password check is the actual gate;
 * this only raises the cost of guessing at it.
 */
export async function checkRateLimit(
  ip: string,
): Promise<{ allowed: boolean; retryAfterSeconds: number }> {
  try {
    const record = await getStore(STORE).get(key(ip), { type: 'json' });
    const attempt = record as AttemptRecord | null;
    if (!attempt) return { allowed: true, retryAfterSeconds: 0 };

    const now = Date.now();
    if (attempt.lockedUntil && attempt.lockedUntil > now) {
      return {
        allowed: false,
        retryAfterSeconds: Math.ceil((attempt.lockedUntil - now) / 1000),
      };
    }
    return { allowed: true, retryAfterSeconds: 0 };
  } catch {
    return { allowed: true, retryAfterSeconds: 0 };
  }
}

export async function recordFailure(ip: string): Promise<void> {
  try {
    const store = getStore(STORE);
    const now = Date.now();
    const existing = (await store.get(key(ip), { type: 'json' })) as AttemptRecord | null;

    const withinWindow = existing && now - existing.first < WINDOW_SECONDS * 1000;
    const next: AttemptRecord = withinWindow
      ? { count: existing.count + 1, first: existing.first }
      : { count: 1, first: now };

    if (next.count >= MAX_ATTEMPTS) next.lockedUntil = now + LOCKOUT_SECONDS * 1000;

    await store.setJSON(key(ip), next);
  } catch {
    // A failed write must not turn a wrong password into a 500.
  }
}

export async function clearAttempts(ip: string): Promise<void> {
  try {
    await getStore(STORE).delete(key(ip));
  } catch {
    // Non-fatal.
  }
}
```

- [ ] **Step 8: Guard `/admin` in the proxy**

Modify `src/proxy.ts`. The guard is a **first pass only** — every server action re-verifies the session itself, because a proxy that is bypassed or misconfigured must not be the only thing between a visitor and a write.

```ts
import { NextResponse, type NextRequest } from 'next/server';
import { isLocale, negotiateLocale, LOCALE_COOKIE } from '@/i18n/locale';
import { SESSION_COOKIE, verifySession } from '@/lib/auth/session';

export async function proxy(request: NextRequest) {
  const { pathname } = request.nextUrl;

  // Admin guard. /admin itself is the login page and stays open.
  if (pathname.startsWith('/admin') && pathname !== '/admin') {
    const valid = await verifySession(request.cookies.get(SESSION_COOKIE)?.value);
    if (!valid) {
      const url = request.nextUrl.clone();
      url.pathname = '/admin';
      return NextResponse.redirect(url, 307);
    }
    return NextResponse.next();
  }

  if (pathname !== '/') return NextResponse.next();

  const cookie = request.cookies.get(LOCALE_COOKIE)?.value;
  const locale = isLocale(cookie)
    ? cookie
    : negotiateLocale(request.headers.get('accept-language'));

  const url = request.nextUrl.clone();
  url.pathname = `/${locale}`;
  return NextResponse.redirect(url, 307);
}

export const config = {
  matcher: ['/((?!api|_next/static|_next/image|favicon.ico|.*\\..*).*)'],
};
```

Create `src/app/(admin)/admin/actions.ts`:

```ts
'use server';

import { cookies, headers } from 'next/headers';
import { redirect } from 'next/navigation';
import { z } from 'zod';
import { verifyPassword } from '@/lib/auth/password';
import {
  createSession,
  SESSION_COOKIE,
  SESSION_COOKIE_OPTIONS,
} from '@/lib/auth/session';
import { checkRateLimit, recordFailure, clearAttempts } from '@/lib/auth/rate-limit';

/** One message for every failure. Distinguishing them tells an attacker which
 *  half they got right. */
const GENERIC_ERROR = 'Incorrect password.';

const loginSchema = z.object({ password: z.string().min(1).max(200) });

async function clientIp(): Promise<string> {
  const store = await headers();
  // Netlify sets x-nf-client-connection-ip; x-forwarded-for is the fallback.
  return (
    store.get('x-nf-client-connection-ip') ??
    store.get('x-forwarded-for')?.split(',')[0]?.trim() ??
    'unknown'
  );
}

export async function login(
  _prevState: { error: string } | null,
  formData: FormData,
): Promise<{ error: string }> {
  const parsed = loginSchema.safeParse({ password: formData.get('password') });
  if (!parsed.success) return { error: GENERIC_ERROR };

  const ip = await clientIp();
  const limit = await checkRateLimit(ip);
  if (!limit.allowed) {
    return {
      error: `Too many attempts. Try again in ${Math.ceil(limit.retryAfterSeconds / 60)} minutes.`,
    };
  }

  if (!(await verifyPassword(parsed.data.password))) {
    await recordFailure(ip);
    return { error: GENERIC_ERROR };
  }

  await clearAttempts(ip);
  (await cookies()).set(SESSION_COOKIE, await createSession(), SESSION_COOKIE_OPTIONS);
  redirect('/admin/dashboard');
}

export async function logout(): Promise<void> {
  (await cookies()).delete(SESSION_COOKIE);
  redirect('/admin');
}
```

The lockout message is the one deliberate exception to the single-error rule: telling a locked-out owner to come back in twelve minutes is worth more than the sliver it reveals, and the lockout is already observable through timing.

```ts
import { revalidateTag } from 'next/cache';
import { blobStore, CONTENT_TAG, projectSchema, type StoredProject } from '@/lib/content';
import { verifySession, SESSION_COOKIE } from '@/lib/auth/session';

type Result = { ok: true } | { ok: false; error: string };

/**
 * Every action re-verifies the session itself.
 *
 * The proxy guard is a first pass and nothing more: a matcher change, a
 * misconfigured route, or a direct action invocation would bypass it entirely.
 * An action that trusts the proxy is an action with no auth.
 */
async function requireSession(): Promise<boolean> {
  return verifySession((await cookies()).get(SESSION_COOKIE)?.value);
}

export async function createProject(formData: FormData): Promise<Result> {
  if (!(await requireSession())) return { ok: false, error: 'Not signed in.' };

  const parsed = projectSchema.safeParse(formDataToProject(formData));
  if (!parsed.success) {
    const missingLocale = parsed.error.issues.some((i) =>
      /title|description/.test(i.path.join('.')),
    );
    return {
      ok: false,
      error: missingLocale
        ? 'Title and description are required in all three languages.'
        : (parsed.error.issues[0]?.message ?? 'Invalid project.'),
    };
  }

  const projects = await blobStore.getProjects();
  if (projects.some((p) => p.id === parsed.data.id)) {
    return { ok: false, error: 'That id is already taken.' };
  }

  await blobStore.saveProjects([...projects, parsed.data]);
  revalidateTag(CONTENT_TAG);
  return { ok: true };
}

export async function updateProject(id: string, formData: FormData): Promise<Result> {
  if (!(await requireSession())) return { ok: false, error: 'Not signed in.' };

  const parsed = projectSchema.safeParse({ ...formDataToProject(formData), id });
  if (!parsed.success) {
    return { ok: false, error: parsed.error.issues[0]?.message ?? 'Invalid project.' };
  }

  const projects = await blobStore.getProjects();
  // id is immutable after creation: it is the image folder name and any link
  // shared to a client.
  await blobStore.saveProjects(projects.map((p) => (p.id === id ? parsed.data : p)));
  revalidateTag(CONTENT_TAG);
  return { ok: true };
}

export async function deleteProject(id: string): Promise<Result> {
  if (!(await requireSession())) return { ok: false, error: 'Not signed in.' };
  const projects = await blobStore.getProjects();
  await blobStore.saveProjects(projects.filter((p) => p.id !== id));
  revalidateTag(CONTENT_TAG);
  return { ok: true };
}

/** Order in the stored array is display order — the same mechanism the bundled
 *  catalogue used, so nothing downstream has to learn a new rule. */
export async function moveProject(id: string, direction: -1 | 1): Promise<Result> {
  if (!(await requireSession())) return { ok: false, error: 'Not signed in.' };

  const projects = await blobStore.getProjects();
  const index = projects.findIndex((p) => p.id === id);
  const target = index + direction;
  if (index === -1 || target < 0 || target >= projects.length) {
    return { ok: false, error: 'Cannot move any further.' };
  }

  const next = [...projects];
  const [moved] = next.splice(index, 1);
  if (moved) next.splice(target, 0, moved);

  await blobStore.saveProjects(next);
  revalidateTag(CONTENT_TAG);
  return { ok: true };
}

function formDataToProject(formData: FormData): Record<string, unknown> {
  const str = (key: string): string => String(formData.get(key) ?? '');
  return {
    id: str('id'),
    title: { ar: str('title.ar'), en: str('title.en'), fr: str('title.fr') },
    description: {
      ar: str('description.ar'),
      en: str('description.en'),
      fr: str('description.fr'),
    },
    category: str('category'),
    frame: str('frame'),
    cover: str('cover'),
    images: formData.getAll('images').map(String).filter(Boolean),
    link: str('link') || undefined,
  };
}
```

Create `src/lib/images/process.ts`:

```ts
import sharp from 'sharp';

export const MAX_UPLOAD_BYTES = 5 * 1024 * 1024;
export const MAX_DIMENSION = 4000;
const WIDTHS = [400, 800, 1200, 1600] as const;

type ImageType = 'jpeg' | 'png' | 'webp' | 'avif';

/**
 * Identify a file from its leading bytes.
 *
 * The filename and the client-sent MIME type are both attacker-controlled and
 * neither is consulted. SVG is deliberately unsupported: it is a script
 * container, and this is the same reason `dangerouslyAllowSVG` was removed from
 * next.config in plan 1.
 */
export function sniffImageType(buffer: Buffer): ImageType | null {
  if (buffer.length < 12) return null;
  if (buffer[0] === 0xff && buffer[1] === 0xd8 && buffer[2] === 0xff) return 'jpeg';
  if (
    buffer
      .subarray(0, 8)
      .equals(Buffer.from([0x89, 0x50, 0x4e, 0x47, 0x0d, 0x0a, 0x1a, 0x0a]))
  ) {
    return 'png';
  }
  if (
    buffer.subarray(0, 4).toString('ascii') === 'RIFF' &&
    buffer.subarray(8, 12).toString('ascii') === 'WEBP'
  ) {
    return 'webp';
  }
  if (
    buffer.subarray(4, 8).toString('ascii') === 'ftyp' &&
    buffer.subarray(8, 12).toString('ascii').startsWith('avif')
  ) {
    return 'avif';
  }
  return null;
}

/**
 * Re-encode an upload to WebP at several widths and produce an LQIP.
 *
 * Re-encoding is the security step, not the optimisation: it drops EXIF (which
 * carries GPS coordinates from a phone camera) and neutralises anything
 * appended to or embedded in the original container, because the output is
 * built from decoded pixels rather than copied bytes.
 */
export async function processUpload(
  buffer: Buffer,
): Promise<{ widths: { width: number; data: Buffer }[]; blurDataURL: string }> {
  if (buffer.length > MAX_UPLOAD_BYTES) {
    throw new Error(
      `Image is too large — the limit is ${MAX_UPLOAD_BYTES / 1024 / 1024} MB.`,
    );
  }
  if (!sniffImageType(buffer)) {
    throw new Error('That file is not a JPEG, PNG, WebP or AVIF image.');
  }

  const source = sharp(buffer, { limitInputPixels: MAX_DIMENSION * MAX_DIMENSION });
  const meta = await source.metadata();
  if ((meta.width ?? 0) > MAX_DIMENSION || (meta.height ?? 0) > MAX_DIMENSION) {
    throw new Error(
      `Image is too large — the limit is ${MAX_DIMENSION}px on either side.`,
    );
  }

  const widths = await Promise.all(
    WIDTHS.filter((w) => w <= (meta.width ?? 0)).map(async (width) => ({
      width,
      data: await sharp(buffer).resize({ width }).webp({ quality: 78 }).toBuffer(),
    })),
  );

  const blur = await sharp(buffer).resize({ width: 16 }).webp({ quality: 40 }).toBuffer();

  return {
    widths:
      widths.length > 0
        ? widths
        : [
            {
              width: meta.width ?? 0,
              data: await sharp(buffer).webp({ quality: 78 }).toBuffer(),
            },
          ],
    blurDataURL: `data:image/webp;base64,${blur.toString('base64')}`,
  };
}
```
